Steps to run our program:
1. CUDA_VISIBLE_DEVICES="" python TrackNetV3/predict.py \
  --video_file assets/badminton.mp4 \
  --tracknet_file TrackNetV3/ckpts/TrackNet_best.pt \
  --inpaintnet_file TrackNetV3/ckpts/InpaintNet_best.pt \
  --save_dir TrackNetV3/output \
  --batch_size 4

        ↓ produces → TrackNetV3/output/badminton_ball.csv

2. python pipeline/processing/extract_pose.py

        ↓ produces → TrackNetV3/output/players_pose_full.csv

3. python pipeline/processing/smooth_ids.py

        ↓ produces → TrackNetV3/output/players_pose_clean.csv

4. python pipeline/analysis/footprint_zones.py

        ↓ produces → data/output/court_zones.csv
                     data/output/zone_footprint.csv

5. python run_pipeline.py

        ↓ runs smooth_ids again (harmless, fast)
          then merge → detect_shots → heatmap
